# Расписание преподавателя

**Расписание преподавателя** - современное одностраничное приложение (SPA) для отображения расписания преподавателя с интерактивным календарем и системой управления временными слотами.

## 🗓️ Функциональность

- **📅 Адаптивные виды календаря** — день, 3 дня, неделя с автоматическим переключением по размеру экрана
- **⏰ 30-минутные интервалы** — детальное планирование с 00:00 до 24:00
- **🎯 Визуальное кодирование** — цветовая система для различных типов слотов
- **🔔 Интерактивные элементы** — клики по слотам с информационными алертами
- **📱 Responsive дизайн** — оптимальное отображение на всех устройствах
- **🔄 Навигация** — плавное перемещение между периодами времени

## 🛠 Технологический стек

- **Frontend**: React 18 + TypeScript
- **Сборка**: Webpack 5 с кастомной конфигурацией
- **Стилизация**: Чистый CSS с адаптивным дизайном
- **State Management**: React Hooks (useState, useEffect)
- **Линтинг**: TypeScript Compiler
- **Разработка**: Hot Module Replacement

## 📋 Системные требования

- Node.js 16+
- npm 8+ или yarn 1.22+
- Современный браузер с поддержкой ES6+

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/hazar84/calendar-apps.git
cd calendar-app
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm run start
```
Приложение будет доступно по адресу: http://localhost:3000

### 4. Сборка для production
```bash
npm run build
```

## 📊 Типы данных

### Расписание преподавателя
```typescript
interface Schedule {
  startTime: string;  // ISO строка
  endTime: string;    // ISO строка
}
```

### Уроки
```typescript
interface Lesson {
  id: number;
  duration: number;   // 30, 60 или 90 минут
  startTime: string;  // ISO строка
  endTime: string;    // ISO строка
  student: string;    // Имя студента
}
```

## 🔧 Структура компонента

### Calendar Props
```typescript
interface CalendarProps {
  view: 'day' | '3days' | 'week';
  startDate: Date;
  schedule: Schedule[];
  lessons: Lesson[];
  onSlotSelect?: (slot: { startTime: Date; endTime: Date }) => void;
}
```

## 📱 Адаптивность

- Desktop (>1024px): Недельный вид (7 дней)
- Tablet (768px-1024px): 3-дневный вид
- Mobile (<768px): Дневной вид с горизонтальным скроллом
